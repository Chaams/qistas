# Demo: an Arabic RAG bot under Qistas

**Nakhla Demo Bank (بنك نخلة التجريبي) is a fictional bank.** Its 12 documents (`corpus.json`) were written for this demo. No real institution is represented.

- `bot.py`: lexical retrieval (Arabic-normalized BM25), answer generated by Claude (`claude-opus-5-5` by default, `DEMO_MODEL` to change it). The bot exposes `POST /chat` and `GET /health`.
- `system_prompt.txt`: the bot's rules (answer only from the documents, in the user's dialect, refuse injections, never repeat personal data).
- `cases/`: 16 cases (11 Q&A across 4 registers including 1 unanswerable question and 1 multi-turn, 3 injections, 2 personal-data cases).
- `qistas.yaml`: thresholds and gate settings.

## Running locally

```bash
pip install "anthropic>=2.14" -e .
export ANTHROPIC_API_KEY=...                       # your key, for the bot AND the judge
python examples/arabic-rag-demo/bot.py &           # http://127.0.0.1:8000
qistas run -c examples/arabic-rag-demo/qistas.yaml
qistas gate results.json -c examples/arabic-rag-demo/qistas.yaml --report-md report.md
```

## In CI

The `.github/workflows/demo.yml` workflow runs the real evaluation on every PR that touches this folder or Qistas itself, and posts the report as a comment. It needs the repository secret `ANTHROPIC_API_KEY`.

The demo PR deliberately degrades `system_prompt.txt` and shows how Qistas blocks the change. Its results appear here once it has run; no number is written in advance.
